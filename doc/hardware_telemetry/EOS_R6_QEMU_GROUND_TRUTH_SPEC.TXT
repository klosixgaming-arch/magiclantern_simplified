- Channel Register Offsets:
    +0x00 (MATCH):   32-bit compare/match period register.
    +0x04 (CONTROL): Channel control register.
                     Write 1 (bit 0 = 1): Starts / enables timer channel.
                     Write 0: Stops / disables timer channel.
    +0x08 (STATUS):  Interrupt status register.
                     Bit 0 indicates compare match reached.
                     Write 1: Clears / acknowledges the status.
    +0x0C (COUNTER): Read-only running 32-bit free counter.

- Cascaded Interrupt Path:
    Marius Timer channels route into the Marius Secondary INTC at 0xD231A000.
    When a Marius timer fires:
      1. Marius INTC asserts GIC SPI 32 (GIC_MariusIntc).
      2. CPU dispatcher at 0xE022D470 reads GICC_IAR (0xC100010C) -> returns 32.
      3. Dispatcher reads secondary interrupt vector from [0xD231A000].
      4. Dispatcher runs registered handler.
      5. Dispatcher writes vector number to [0xD231A010] (Marius EOI).
      6. Dispatcher writes 32 to GICC_EOIR (0xC1000110).
